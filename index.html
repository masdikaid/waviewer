Guide: How to Obtain WhatsApp Database & Key

1

Original Database Location (msgstore.db)

On rooted Android devices, the unencrypted SQLite database is stored directly in the system directory:

/data/data/com.whatsapp/databases/msgstore.db
2

Key File Location (key)

The 158-byte WhatsApp AES encryption key file is stored in WhatsApp's private directory:

/data/data/com.whatsapp/files/key
3

How to Pull Files Using ADB (Computer)

Connect your Android phone to your computer with USB Debugging enabled, then run the following terminal command:

adb root && adb pull /data/data/com.whatsapp/databases/msgstore.db .
1

Crypt Backup Location in Internal Storage

WhatsApp automatically creates daily local backups formatted as .crypt14 or .crypt15 in internal storage:

/sdcard/Android/media/com.whatsapp/WhatsApp/Databases/msgstore.db.crypt14

(For Android 10 and below: /sdcard/WhatsApp/Databases/msgstore.db.crypt12)

2

Copy File to Computer

Use a USB data cable or a file manager app on your phone to copy the latest msgstore.db.crypt14 file to your computer.

1

64-Digit End-to-End Encrypted Backup Key (Crypt15)

If you enable "End-to-end encrypted backup" under WhatsApp Settings > Chats > Chat backup, WhatsApp provides a 64-character hexadecimal key. You can type or paste that key directly into this app.

2

158-Byte Key File (Crypt12 / Crypt14)

This file is generated automatically by the WhatsApp system at /data/data/com.whatsapp/files/key. The last 32 bytes of this file contain the secret AES-256 key used to decrypt the database.

🔒

Is my WhatsApp chat data secure?

Completely secure. This app performs 100% of decryption and database parsing locally in your browser using WebCrypto and WebAssembly. No data bytes, chat texts, or keys are ever transmitted to any remote server.

⚡

Do I need to provide a key for a standard msgstore.db?

No! If your uploaded file is an unencrypted SQLite file (directly extracted or already decrypted), the viewer automatically detects it and opens the chat history immediately without prompting for a key.

📎

How do media attachments & documents work?

WhatsApp stores chat history, metadata, and low-res thumbnails inside msgstore.db, while full-resolution photos, videos, and documents stay in your phone's storage. In the viewer, thumbnails, document names, voice notes, locations, and stickers appear automatically. You can also click the Link Media Folder icon in the header to connect your local WhatsApp/Media folder and view original files directly.
